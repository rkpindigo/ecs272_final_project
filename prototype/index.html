Oscars Representation: Data Story Prototypes

Multiple chapters with explicit chart labels and explanations. Data sources are local in data/.

Chapter 0: Overview Bubble Plot

Graph Kind (Searchable Name): Bubble plot / Scatter plot with sized marks
What It Shows: Every nomination/win as its own mark across time and category groups
Element Meaning: Each bubble = one entry; color = race; symbol = gender; size = winner vs nominee
Notes: Hover for details; grouped by category group for readability

Chapter 1: Overall Representation Over Time

Graph Kind (Searchable Name): Multi-series line chart (time series) + parity-gap line
What It Shows: Share of Female nominees vs winners, Non‑White nominees vs winners, and White‑Male nominees vs winners by ceremony year
Element Meaning: Each point = one ceremony year; each line = share for a group; dotted line = winners; solid line = nominees
Notes: All categories combined; Non‑White = Asian + Black + Hispanic; White‑Male = Race=White and Gender=Male; includes 2015 marker

Chapter 1.1: Toggle View (Gender vs Race)

Graph Kind (Searchable Name): Multi-series line chart with toggle
What It Shows: Toggle between Gender shares (Female vs Male) and Race shares (White vs Non‑White), nominees vs winners over time
Element Meaning: Solid lines = nominees; dashed lines = winners; toggle switches the grouping
Notes: This is for exploration to see if patterns differ by grouping

Chapter 2: Category Groups and Gender Shifts

Graph Kind (Searchable Name): Full-width bar chart series (by decade)
What It Shows: Female share of nominees by decade, one full chart per category group
Element Meaning: Each bar = one decade; bar height = female nominee share in that group
Notes: Category groups are auto-generated by keyword matching (Acting, Directing, Writing, Music, Technical, Picture/Production, Other)

Chapter 3: Directors Spotlight (Cumulative)

Graph Kind (Searchable Name): Cumulative line chart
What It Shows: Cumulative counts of director nominations and wins by gender over time
Element Meaning: Each line = gender + nomination/win; higher = more total recognition so far
Notes: Data from Oscar Winners - Director.csv (directing only)

Chapter 3.1: Directors by Decade (Share)

Graph Kind (Searchable Name): Bar chart (share by decade)
What It Shows: Female share of director nominations vs wins by decade
Element Meaning: Each bar = decade; height = female share; color = nomination vs win
Notes: If shares stay near zero, it highlights the lack of progress in this category

Chapter 4: Race by Category Group (Radar / Spider)

Graph Kind (Searchable Name): Radar chart / Spider chart
What It Shows: Race share of nominees across category groups for two time windows
Element Meaning: Each axis = category group; polygon radius = race share in that group
Notes: Two panels: early period (1928–1989) vs recent (1990–2020). Uses square‑root scaling so small shares are visible.

Chapter 4.1: Race × Category Group Heatmap (Recent)

Graph Kind (Searchable Name): Heatmap
What It Shows: Nominee share by race across category groups (1990–2020)
Element Meaning: Each cell = share of nominees for a race in a category group; darker = higher share
Notes: Adds a zoom-in view to see which groups are most/least diverse in recent years

Chapter 4.2: Race Share Over Time

Graph Kind (Searchable Name): Stacked area chart
What It Shows: Share of nominees by race over time (all categories)
Element Meaning: Each band = race; band thickness = share in that year
Notes: Shows evolution in overall representation across time

Chapter 4.3: Race–Gender Winners Matrix (Pre/Post 2015)

Graph Kind (Searchable Name): Matrix with embedded bar indicators (not heatmap)
What It Shows: Share of winners by Race × Gender, comparing pre‑2015 vs post‑2015
Element Meaning: Each cell = race‑gender group; bar length = winner share
Notes: Toggle switches time window; uses all categories

Chapter 4.4: Progress Bullet Plot (Nominees vs Winners)

Graph Kind (Searchable Name): Bullet chart
What It Shows: Nominee share (benchmark) vs winner share for each race‑gender group
Element Meaning: Gray bar = nominee share; colored marker = winner share
Notes: Shows whether winners track nominees for each group

Appendix: Age at Win (Historical)

Graph Kind (Searchable Name): Scatterplot + rolling average line
What It Shows: Individual winner ages per year with a rolling average trend by gender
Element Meaning: Each dot = one winner; line = 7‑year rolling average
Notes: Winners-only data; coverage ends in 2005

Chapter 5.1: Outliers vs Typical Ages

Graph Kind (Searchable Name): Line chart (rolling mean vs rolling median)
What It Shows: Rolling mean and median ages by gender to reveal outlier effects
Element Meaning: Solid = median; dashed = mean; gaps indicate outlier influence
Notes: If mean stays above median, it suggests high-age outliers pulling averages up

Prototypes built with D3.js (CDN) and local datasets in data/processed.
